## Rules that keep this readable

- One page per question. If a page grows two subjects, split it.
- Lead with what a reader does, then explain why it works that way.
- Prefer a short table or a numbered list over a paragraph.
- Every command must be copy-pasteable and current.

Test suites live outside this folder, in [`/tests`](../tests/).
