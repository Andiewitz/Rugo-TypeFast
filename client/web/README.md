# @kit/web

Astro site for Type Fast.

## Development

From the repository root:

```bash
npm install
npm run dev:web
```

The dev server runs at http://localhost:4321. Build with `npm run build`, which writes `client/web/dist`.

## Layout

- `src/pages/` - one route per file; `index.astro` is the home page
- `public/` - static assets served as-is

Repository-wide setup and conventions are in [`docs/contributor-guides/README.md`](../../docs/contributor-guides/README.md).
